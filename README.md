# This is an empty Project Template
This project template includes the following:

Backend: Python + Flask
Frontend: NodeJS + React + Bootstrap

Everything is packed into a docker container which can be run via 'docker-compose up --build'

In the 'scripts' -folder you will find all the React and Bootstrap coding. The compiled bundle-files however will be served by Flask and are therefore moved into flaskr/static/dist. Webpack is configured accordingly.

Have fun!
